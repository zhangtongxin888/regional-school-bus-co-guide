# regionalschoolbusco.wiki

Static guide for the Roblox game **Regional School Bus Co** (place 93172673274529, Regional Bus Community).

The repo root is the deploy root that Vercel serves (project `regional-school-bus-co-guide`).
Since 2026-10-01 the HTML is generated. Edit `scripts/site_data.py` (facts) or `scripts/build.py` (copy and layout), then run:

```
npm run check   # build → lint → SEO audit → tests (python3 only, no dependencies)
```

Rules: date every live number. Never publish a code without 3+ independent working sources. Only the homepage targets "Regional School Bus Co Wiki".
