Quick-start structure

The first-session loop

Learn this verified high-level order, then use the detailed guide for the items that still depend on live prompts.

  1. 01

    Start at the Bus Yard

    Use the Bus Yard as the dependable starting point. The old Spawn Anywhere pass is currently off sale, so do not plan around spawning anywhere.

  2. 02

    Choose a public bus and number

    Standard public buses can be driven by anyone. Pick one in the yard and set a bus number using the live interface.

  3. 03

    Transport students

    Run a student-transport route through Upstate Region. Follow the current prompts for the route, stops, and completion signal.

  4. 04

    Watch fuel and refuel

    Fuel is part of the driving loop. Use the live gauge and refuel as needed; fuel range, price, and station details are not published here.

  5. 05

    Finish, then repeat

    Finish the route, start another cycle, or join an organized route session when one is available to you.
